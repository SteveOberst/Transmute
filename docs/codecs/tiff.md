# TIFF

| Property | Value |
|----------|-------|
| Constant | `ImageFormat.Tiff` |
| MIME type | `image/tiff` |
| Extension | `tiff` |
| Container | TIFF |

## Platform availability

| Platform | Decode | Encode |
|----------|--------|--------|
| Android  | built-in | built-in |
| Desktop  | built-in | built-in |
| iOS      | built-in | built-in |

## Encode options

No format-specific options.

## Metadata support

TIFF files may carry: `ExifMetadata`, `XmpMetadata`, `IccProfileMetadata`.

## Structure support

`TiffStructure` — IFD directory and tag list.
